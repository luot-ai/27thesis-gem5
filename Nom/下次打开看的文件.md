## v2b 要做的核心事情

1. 在 IQ / non-spec 发射路径里检查 stream readyMap。
2. SSS ready 条件：
   - `loadreadyMap[src0][idx0] != 0`
   - `loadreadyMap[src1][idx1] != 0`
   - `storereadyMap[dst_idx] == false`
3. 不 ready 就不能调用 `StreamEngine::sssAdd(...)`。
4. `StreamEngine::sssAdd(...)` 建模为：
   - cycle 0: readop
   - cycle 1: calculate
   - cycle 2: writeback
5. writeback 时更新：
   - source load ready 递减
   - destination FIFO 写结果
   - destination store ready 置位
