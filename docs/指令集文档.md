# Stream Custom Instruction Set Specification v0.6

## 1. 指令格式

所有 Stream 自定义指令均采用 RISC-V R-type custom instruction 格式：

```asm
.insn r opcode, funct3, funct7, rd, rs1, rs2
```

对应 R-type 编码格式如下：

```text
31        25 24    20 19    15 14  12 11     7 6      0
+-----------+--------+--------+------+--------+--------+
|  funct7   |  rs2   |  rs1   |funct3|   rd   | opcode |
+-----------+--------+--------+------+--------+--------+
```

统一使用：

```text
opcode = 0x0b
```

该 opcode 属于 RISC-V `custom-0` 编码空间。
---
## 2. 一级分类：funct3

| `funct3` |  二进制 | 类别         | 说明                                    |
| ---------: | ------: | ------------ | --------------------------------------- |
|      `0` | `000` | `CFG`      | Stream 配置类指令                       |
|      `1` | `001` | `RESERVED` | 保留                                    |
|      `2` | `010` | `RESERVED` | 保留                                    |
|      `3` | `011` | `RESERVED` | 保留                                    |
|      `4` | `100` | `RESERVED` | 保留                                    |
|      `5` | `101` | `RESERVED` | 保留                                    |
|      `6` | `110` | `SSR`      | 计算类指令：stream + stream -> register |
|      `7` | `111` | `SSS`      | 计算类指令：stream + stream -> stream   |

当前版本包含两类指令：

```text
1. Stream 配置类指令
2. Stream 计算类指令
```

其中计算类指令包含：

```text
SSS : stream + stream -> stream
SSR : stream + stream -> register
```

# 3. CFG：Stream 配置类指令

```text
funct3 = 000
```

CFG 类指令用于配置 Stream 的迭代参数、索引推进参数、stride、reuse 以及访存首地址。

统一格式为：

```text
opcode = 0x0b
funct3 = 000
funct7 = cfg_id
rd     = x0
rs1    = cfg_value
rs2    = fifo_id
```

字段说明：

| 字段       | 含义                                                |
| ---------- | --------------------------------------------------- |
| `rd`     | 固定为`x0`，表示不写回通用寄存器                  |
| `rs1`    | 配置值，例如迭代参数、stride、reuse 或 base address |
| `rs2`    | 目标 fifo 编号                                      |
| `funct7` | 配置子功能编号`cfg_id`                            |

CFG 指令会修改 Stream Engine 内部配置状态。

---

## 3.1 CFG 子功能表

| `cfg_id` / `funct7` | 指令               | `rs1`                             | `rs2`     | 说明                                                  |
| ----------------------: | ------------------ | ----------------------------------- | ----------- | ----------------------------------------------------- |
|                   `0` | `cfg_iter`       | `{length[15:0], outerIter[15:0]}` | `fifo_id` | 配置block数量(outeriter)和block内word<br />数(length) |
|                   `1` | `cfg_i_limit`    | `limit`                           | `fifo_id` | 配置索引推进上限                                      |
|                   `2` | `cfg_i_repeat`   | `repeat`                          | `fifo_id` | 配置局部重复次数                                      |
|                   `3` | `cfg_stride`     | `stride`                          | `fifo_id` | 配置 word stride                                      |
|                   `4` | `cfg_tilestride` | `tilestride`                      | `fifo_id` | 配置 tile stride                                      |
|                   `5` | `cfg_reuse`      | `reuse`                           | `fifo_id` | 配置每个word的复用次数                                |
|                   `6` | `cfg_L2_load`    | `base_addr`                       | `fifo_id` | 配置接口为连接L2 cache，以及 load 首地址             |
|                   `7` | `cfg_axi_load`   | `base_addr`                       | `fifo_id` | 配置接口为连接AXI，以及 load 首地址                  |
|                   `8` | `cfg_store`      | `base_addr`                       | `fifo_id` | 配置 store 首地址(接口为连接L2 Cache)                 |
|             `9 ~ 127` | `reserved`       | -                                   | -           | 保留                                                  |

## 3.2 `cfg_iter`

```c
cfg_iter(int outerIter, int length, int fifo_id)
```

编码：

```text
opcode = 0x0b
funct3 = 000
funct7 = 0
rd     = x0
rs1    = { length[15:0], outerIter[15:0] }
rs2    = fifo_id
```

`rs1` 打包格式：

```text
31              16 15               0
+----------------+------------------+
| length[15:0]   | outerIter[15:0]  |
+----------------+------------------+
```

含义：

```text
配置指定 fifo 的 block 数 outerIter 和每 block 的 word 数 length。
```

# 4. Compute 指令总览

Compute 指令分为两类：

```text
SSS : stream + stream -> stream
SSR : stream + stream -> register
```

两类计算指令共用同一张 `op_id` 表。

对于 compute 指令：

```text
funct7[6:5] = reserved，当前固定为 0
funct7[4:0] = op_id
```

字段划分如下：

```text
6       5 4                 0
+---------+------------------+
| reserve |      op_id       |
+---------+------------------+
```

---

# 5. Compute op_id 表

`SSS / SSR` 共用以下 `op_id` 表。

|       `op_id` |    二进制 | 操作         | 含义                           |
| --------------: | --------: | ------------ | ------------------------------ |
|        `0x00` | `00000` | `ADD`      | `src0 + src1`                |
|        `0x01` | `00001` | `SLL`      | `src0 << src1[4:0]`          |
|        `0x02` | `00010` | `SLT`      | signed less-than               |
|        `0x03` | `00011` | `SLTU`     | unsigned less-than             |
|        `0x04` | `00100` | `XOR`      | `src0 ^ src1`                |
|        `0x05` | `00101` | `SRL`      | logical right shift            |
|        `0x06` | `00110` | `OR`       | `src0 \| src1`                |
|        `0x07` | `00111` | `AND`      | `src0 & src1`                |
|        `0x08` | `01000` | `SUB`      | `src0 - src1`                |
|        `0x0d` | `01101` | `SRA`      | arithmetic right shift         |
|        `0x10` | `10000` | `MUL`      | low XLEN bits of multiply      |
|        `0x11` | `10001` | `MULH`     | signed × signed high bits     |
|        `0x12` | `10010` | `MULHSU`   | signed × unsigned high bits   |
|        `0x13` | `10011` | `MULHU`    | unsigned × unsigned high bits |
|        `0x14` | `10100` | `DIV`      | signed divide                  |
|        `0x15` | `10101` | `DIVU`     | unsigned divide                |
|        `0x16` | `10110` | `REM`      | signed remainder               |
|        `0x17` | `10111` | `REMU`     | unsigned remainder             |
| `0x18 ~ 0x1f` |         - | `reserved` | 保留                           |

说明：

```text
0x00 ~ 0x0f : ALU 类操作
0x10 ~ 0x17 : MUL / DIV 类操作
0x18 ~ 0x1f : 保留
```

# 6. SSS：stream + stream -> stream

```text
funct3 = 111
```

SSS 是计算类指令，用于从两个 stream 中读取数据，执行 `op_id` 指定的计算，并将结果写入目标 stream。

统一格式：

```text
opcode = 0x0b
funct3 = 111
funct7 = { 2'b00, op_id[4:0] }
rd     = x0
rs1    = { src1_fifo_id[1:0], src0_fifo_id[1:0] }
rs2    = dst_fifo_id
```

`rs1` 打包格式：

```text
31          4 3              2 1              0
+------------+----------------+----------------+
| reserved   | src1_fifo_id   | src0_fifo_id   |
+------------+----------------+----------------+
```

字段说明：

| 字段            | 含义              |
| --------------- | ----------------- |
| `rd`          | 固定为`x0`      |
| `rs1[1:0]`    | 源 fifo 0 编号    |
| `rs1[3:2]`    | 源 fifo 1 编号    |
| `rs1[31:4]`   | 保留              |
| `rs2`         | 目标 fifo 编号    |
| `funct7[4:0]` | 计算操作`op_id` |

示例：

| 指令        | `funct3` | `op_id` | `funct7` | 含义                        |
| ----------- | ---------: | --------: | ---------: | --------------------------- |
| `sss_add` |    `111` |  `0x00` |   `0x00` | stream0 + stream1 -> stream |
| `sss_sub` |    `111` |  `0x08` |   `0x08` | stream0 - stream1 -> stream |
| `sss_mul` |    `111` |  `0x10` |   `0x10` | stream0 * stream1 -> stream |
| `sss_and` |    `111` |  `0x07` |   `0x07` | stream0 & stream1 -> stream |

---

# 7. SSR：stream + stream -> register

```text
funct3 = 110
```

SSR 是计算类指令，用于从两个 stream 中读取数据，执行 `op_id` 指定的计算，并将结果写回通用寄存器 `rd`。

统一格式：

```text
opcode = 0x0b
funct3 = 110
funct7 = { 2'b00, op_id[4:0] }
rd     = result_reg
rs1    = { src1_fifo_id[1:0], src0_fifo_id[1:0] }
rs2    = x0
```

`rs1` 打包格式：

```text
31          4 3              2 1              0
+------------+----------------+----------------+
| reserved   | src1_fifo_id   | src0_fifo_id   |
+------------+----------------+----------------+
```

字段说明：

| 字段            | 含义                 |
| --------------- | -------------------- |
| `rd`          | 结果写回的通用寄存器 |
| `rs1[1:0]`    | 源 fifo 0 编号       |
| `rs1[3:2]`    | 源 fifo 1 编号       |
| `rs1[31:4]`   | 保留                 |
| `rs2`         | 固定为`x0`         |
| `funct7[4:0]` | 计算操作`op_id`    |

示例：

| 指令        | `funct3` | `op_id` | `funct7` | 含义                    |
| ----------- | ---------: | --------: | ---------: | ----------------------- |
| `ssr_add` |    `110` |  `0x00` |   `0x00` | stream0 + stream1 -> rd |
| `ssr_sub` |    `110` |  `0x08` |   `0x08` | stream0 - stream1 -> rd |
| `ssr_mul` |    `110` |  `0x10` |   `0x10` | stream0 * stream1 -> rd |
| `ssr_slt` |    `110` |  `0x02` |   `0x02` | stream0 < stream1 -> rd |

# 10. 版本说明

当前版本将 Stream 指令划分为配置类指令和计算类指令。

配置类指令统一使用：

```text
funct3 = 000
```

包括：

```text
迭代配置
索引推进配置
stride 配置
reuse 配置
load / store 首地址配置
```

计算类指令包含：

```text
SSS : stream + stream -> stream
SSR : stream + stream -> register
```

两类计算指令共用统一的 `op_id` 表，`op_id` 编码在 `funct7[4:0]` 中。`funct7[6:5]` 当前保留，固定为 `0`。
